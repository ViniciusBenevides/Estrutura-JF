📊 Sistema de Verificação de Verossimilhança

Sistema web desenvolvido em Django para análise de similaridade entre descrições de itens e o Catálogo Nacional de Bens e Serviços (CNBS). O sistema processa arquivos Excel, compara descrições usando técnicas de processamento de linguagem natural e gera relatórios com itens de baixa verossimilhança.

🚀 Características

  • Upload de Arquivos Excel: Interface web para upload de arquivos .xlsx
  • Análise de Similaridade: Comparação usando modelos de transformers e NLTK
  • Integração com CNBS: Consulta automática à API do Catálogo Nacional de Bens e Serviços
  • Processamento Assíncrono: Processamento em background para arquivos grandes
  • Relatórios Detalhados: Geração de relatórios Excel com resultados da análise
  • Histórico de Processamentos: Acompanhamento de todos os processamentos realizados
  • Interface Responsiva: Design moderno e responsivo
  • Logs Detalhados: Sistema de logging para monitoramento e debug

📋 Pré-requisitos

Antes de iniciar a instalação, certifique-se de ter os seguintes requisitos:

Sistema Operacional

  • Windows 10/11, macOS 10.14+, ou Linux (Ubuntu 18.04+)

Software Necessário

  • Python 3.11 ou superior - Download Python
  • Git - Download Git
  • Editor de código (recomendado: VS Code, PyCharm)

Verificação dos Pré-requisitos

python --version
pip --version
git --version

🔧 Instalação

1. Clone o Repositório

git clone https://github.com/seu-usuario/verossimilhanca.git
cd verossimilhanca

2. Criar Ambiente Virtual

python -m venv venv
venv\Scripts\activate
# ou
source venv/bin/activate

3. Instalar Dependências

pip install --upgrade pip
pip install -r requirements.txt

4. Configurar Banco de Dados

python manage.py migrate
python manage.py createsuperuser

5. Coletar Arquivos Estáticos

python manage.py collectstatic --noinput

⚙️ Configuração

Variáveis de Ambiente (Opcional)

DEBUG=True
SECRET_KEY=sua-chave-secreta-aqui
ALLOWED_HOSTS=localhost,127.0.0.1
CNBS_API_BASE_URL=https://cnbs.estaleiro.serpro.gov.br/cnbs-api/material/v1/
SIMILARITY_THRESHOLD=0.65
MAX_FILE_SIZE=10485760

🚀 Execução

python manage.py runserver

Acesse http://127.0.0.1:8000/

📖 Uso

  1. Acesse a página inicial e envie um arquivo Excel válido (.xlsx)
  2. Acompanhe o processamento
  3. Baixe o resultado gerado

🔌 API

Upload de Arquivo

POST /api/upload/
Content-Type: multipart/form-data
{
  "arquivo": <arquivo.xlsx>
}

Status do Processamento

GET /api/status/{processamento_id}/
{
  "status": "CONCLUIDO",
  "progresso": 100,
  "total_itens": 150,
  "total_baixas": 25,
  "arquivo_resultado": "/media/downloads/resultado.xlsx"
}
