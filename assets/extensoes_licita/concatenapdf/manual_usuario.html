📘 Manual do Usuário - Concatenador de PDFs

📖 Sobre o Sistema

O Concatenador de PDFs é uma ferramenta web desenvolvida para unir múltiplos arquivos PDF em um único documento de forma rápida e intuitiva. O sistema foi projetado para ser simples e acessível.

🎯 Para que serve?

  • Unir múltiplos documentos PDF em um só.
  • Facilitar o envio e arquivamento de documentos relacionados.
  • Otimizar a organização de arquivos digitais.

🚀 Como usar o sistema

1. Acessando o Sistema

  1. Abra seu navegador (Chrome, Firefox, etc.).
  2. Acesse http://127.0.0.1:8000/.
  3. A interface principal de concatenação será exibida.

🖥️ Interface do Sistema

  • Área de Upload: arraste e solte arquivos PDF.
  • Botão de Seleção: selecione arquivos manualmente.
  • Enviar e Concatenar: inicia o processo.
  • Área de Mensagens: exibe status, erros e link de download.

💡 Fluxo de Uso

📄 Selecionar PDFs → ⚡ Enviar e Concatenar → 📊 Baixar Resultado

2. Selecionando os Arquivos

  • Arraste e solte múltiplos arquivos PDF na área pontilhada.
  • Ou clique para selecionar manualmente no seu computador.

3. Processando os Arquivos

  1. Selecione pelo menos dois arquivos PDF.
  2. Clique em "Enviar e Concatenar".
  3. O botão indicará “Processando...” até a conclusão.

4. Baixando o Resultado

  1. Após o processamento, uma mensagem de sucesso será exibida.
  2. O download iniciará automaticamente, ou clique no link manualmente.

⚠️ Requisitos e Limitações

  • ✅ Formato: apenas .pdf
  • ✅ Mínimo: 2 arquivos
  • ✅ Tamanho máximo: 10MB por arquivo
  • ❌ Não processa PDFs protegidos por senha
  • ❌ Ordem segue a seleção dos arquivos

🔧 Solução de Problemas

  • “Selecione pelo menos dois arquivos PDF.” → Escolha dois ou mais arquivos.
  • “Apenas arquivos PDF são permitidos.” → Certifique-se de enviar somente PDFs.
  • “Erro na comunicação com o servidor.” → Verifique sua internet e recarregue.
  • O arquivo não baixa automaticamente → Clique com o botão direito e escolha “Salvar link como...”.
