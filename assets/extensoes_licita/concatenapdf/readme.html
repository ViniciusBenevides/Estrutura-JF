📄 Concatenador de PDFs - Sistema Web

Sistema web desenvolvido em Django para concatenação (junção) de múltiplos arquivos PDF em um único documento. Ideal para unificar documentos relacionados de forma rápida e eficiente.

🚀 Funcionalidades

  • ✅ Upload de múltiplos arquivos PDF via drag & drop ou seleção manual
  • ✅ Concatenação automática mantendo a qualidade original
  • ✅ Interface moderna e responsiva
  • ✅ Download automático do arquivo concatenado
  • ✅ Validação de arquivos (apenas PDFs aceitos)
  • ✅ Limite de tamanho configurável (10MB por padrão)
  • ✅ Histórico de processamentos
  • ✅ Interface em português brasileiro

🛠️ Tecnologias Utilizadas

  • Backend: Django 3.2.25
  • Processamento PDF: PyPDF2 3.0.1
  • Imagens: Pillow 10.4.0
  • Frontend: HTML5, CSS3, JavaScript
  • Banco de dados: SQLite

📋 Pré-requisitos

Certifique-se de ter:

python --version

🔧 Instalação

1. Clone o Repositório

git clone <URL_DO_REPOSITORIO>
cd concatenapdf

2. Crie um Ambiente Virtual

python -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows

3. Instale Dependências

pip install -r requirements.txt

4. Configure o Banco de Dados

python manage.py makemigrations
python manage.py migrate

5. Crie um Superusuário (opcional)

python manage.py createsuperuser

6. Execute o Servidor

python manage.py runserver

➡️ Acesse http://127.0.0.1:8000/

🎯 Como Usar

  1. Acesse o sistema em http://127.0.0.1:8000/
  2. Arraste e solte os arquivos PDF ou selecione-os manualmente
  3. Aguarde o processamento
  4. O download do arquivo concatenado iniciará automaticamente

🐛 Solução de Problemas

  • Erro “Couldn't import Django”: reative o venv e reinstale dependências
  • Erro “No module named 'PyPDF2'”: instale PyPDF2
  • Erro de permissão: crie e permita gravação em media/uploads/

🔒 Segurança

  • Defina DEBUG=False
  • Configure SECRET_KEY e ALLOWED_HOSTS
  • Use PostgreSQL/MySQL em produção
  • Implemente Nginx + Gunicorn
