Sistema de Transcrição Jurídica - Django

Sistema web para análise automatizada de transcrições de sentenças jurídicas utilizando inteligência artificial.

📋 Descrição

Este sistema permite o upload de arquivos PDF ou TXT contendo transcrições de sentenças jurídicas e realiza análise automatizada utilizando a API da DeepSeek. O resultado é apresentado em formato HTML estruturado e pode ser exportado como PDF.

🚀 Funcionalidades

  • Upload de Arquivos: Suporte para arquivos PDF e TXT
  • Análise com IA: Processamento automatizado usando DeepSeek API
  • Interface Web: Interface moderna e responsiva
  • Exportação PDF: Geração de relatórios em PDF
  • Histórico: Acompanhamento de processos anteriores
  • Admin Panel: Interface administrativa Django

🛠️ Tecnologias Utilizadas

  • Backend: Django 5.1.5
  • Frontend: HTML5, CSS3, JavaScript
  • IA: DeepSeek API
  • PDF: pdfkit, pdfplumber
  • Banco de Dados: SQLite (desenvolvimento)
  • Servidor: Gunicorn (produção)

📦 Instalação

Pré-requisitos

  • Python 3.8+
  • pip
  • wkhtmltopdf (para geração de PDFs)

Passo a passo

  1. Clone o repositório
bash
git clone 
cd ProjetoTranscricao
  1. Crie um ambiente virtual
bash
python -m venv venv
  1. Ative o ambiente virtual
bash

Windows

venv\Scripts\activate
Linux/Mac

source venv/bin/activate
  1. Instale as dependências
bash
pip install -r requirements.txt
  1. Configure as variáveis de ambiente
Crie um arquivo .env na raiz do projeto: 
env
SECRET_KEY=sua_chave_secreta_django
DEBUG=True
DEEPSEEK_API_KEY=sua_chave_api_deepseek
OPENAI_API_KEY=sua_chave_api_openai
WKHTMLTOPDF_PATH=caminho_para_wkhtmltopdf
  1. Execute as migrações
bash
python manage.py makemigrations
python manage.py migrate
  1. Crie um superusuário (opcional)
bash
python manage.py createsuperuser
  1. Inicie o servidor
bash
python manage.py runserver

O sistema estará disponível em http://127.0.0.1:8000/

🔧 Configuração

wkhtmltopdf

Para geração de PDFs, instale o wkhtmltopdf:

  • Windows: Baixe de https://wkhtmltopdf.org/downloads.html
  • Ubuntu/Debian: sudo apt-get install wkhtmltopdf
  • CentOS/RHEL: sudo yum install wkhtmltopdf

Configure o caminho no arquivo .env: 

env
WKHTMLTOPDF_PATH=C:\Program Files\wkhtmltopdf\bin\wkhtmltopdf.exe

APIs de IA

Configure suas chaves de API no arquivo .env:

  • DeepSeek: Obtenha em https://platform.deepseek.com/
  • OpenAI: Obtenha em https://platform.openai.com/

🎯 Como Usar

  1. Acesse a página inicial em http://127.0.0.1:8000/
  1. Faça upload de um arquivo PDF ou TXT
  1. Aguarde o processamento da análise
  1. Visualize o resultado formatado
  1. Baixe o PDF se necessário
  1. Consulte o histórico de processos anteriores
