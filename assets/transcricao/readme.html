Sistema de Transcrição Jurídica - Django

Sistema para transcrição e resumo de audiências judiciais, com geração de relatório estruturado e exportação em PDF nomeado pelo número do processo.

Funcionalidades

  • Aceita arquivos PDF e TXT de ata ou transcrição de audiência.
  • Gera resumo jurídico detalhado usando IA (DeepSeek API).
  • Exporta o resultado em PDF, nomeado com o número do processo.
  • Interface web moderna desenvolvida em Django.
  • Sistema de histórico de processos.
  • Interface responsiva e intuitiva.

Como usar

  1. Acesse http://localhost:8000 no navegador.
  1. Envie o arquivo da audiência (PDF ou TXT).
  1. Visualize o resumo gerado.
  1. Baixe o PDF do resultado.
  1. Consulte o histórico de processos anteriores.

Instalação

Veja a seção abaixo para instruções detalhadas.

---

Documentação Técnica de Instalação

Requisitos

  • Python 3.9+
  • Pip
  • Navegador web
  • wkhtmltopdf instalado

Dependências Python

  • Django 5.1.5
  • pdfplumber
  • pdfkit
  • openai
  • python-dotenv
  • E outras (veja requirements.txt)

Instalação

bash
git clone https://github.com/Residentes-JF/transcricao.git
cd transcricao
python -m venv venv

Windows:

.\venv\Scripts\Activate.ps1

Linux/Mac:

source venv/bin/activate
pip install -r requirements.txt
Instale o wkhtmltopdf:


Windows: https://wkhtmltopdf.org/downloads.html


Linux: sudo apt install wkhtmltopdf


Mac: brew install wkhtmltopdf
Configure sua chave da API DeepSeek:

echo "DEEPSEEK_API_KEY=sua_chave_aqui" > .env
Execute as migrações:

python manage.py migrate
Inicie o servidor:

python manage.py runserver

O sistema estará disponível em http://localhost:8000.

Documentação do Usuário

Passo a Passo

  1. Abra o navegador e acesse http://localhost:8000.
  1. Clique em "Escolher arquivo" e envie o arquivo da audiência (PDF ou TXT).
  1. Clique em "Analisar" para gerar o resumo.
  1. Visualize o resultado na tela.
  1. Clique em "Baixar como PDF" para salvar o relatório.
  1. Use o menu "Histórico" para consultar processos anteriores.

Funcionalidades Principais

  • Upload de Arquivos: Suporte para PDF e TXT
  • Análise com IA: Processamento usando DeepSeek API
  • Geração de PDF: Download automático com nome do processo
  • Histórico: Acompanhamento de todos os processos
  • Interface Responsiva: Funciona em desktop e mobile

Observações

  • O sistema aceita arquivos PDF e TXT.
  • O PDF gerado será nomeado com o número do processo extraído do texto.
  • Todos os processos ficam salvos no histórico para consulta posterior.
  • Para dúvidas técnicas, consulte a documentação completa em README_DJANGO.md.
