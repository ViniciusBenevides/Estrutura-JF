Manual do Usuário - Sistema de Transcrição Jurídica Django

📖 Introdução

O Sistema de Transcrição Jurídica é uma aplicação web desenvolvida em Django que permite a análise automatizada de transcrições de sentenças jurídicas utilizando inteligência artificial. Este manual irá guiá-lo através de todas as funcionalidades do sistema.

🚀 Primeiros Passos

Acessando o Sistema

  1. Abra seu navegador web
  1. Digite o endereço: http://127.0.0.1:8000/ (desenvolvimento) ou o endereço fornecido pelo administrador
  1. A página inicial será exibida

Interface Principal

A interface é composta por:

  • Cabeçalho: Logo e navegação
  • Área de Upload: Para envio de arquivos
  • Instruções: Como usar o sistema
  • Rodapé: Informações de copyright

📁 Upload de Arquivos

Tipos de Arquivo Suportados

O sistema aceita os seguintes formatos:

  • PDF: Arquivos de transcrição em formato PDF
  • TXT: Arquivos de texto simples

Como Fazer Upload

  1. Na página inicial, clique no botão "Escolher arquivo"
  1. Selecione o arquivo desejado em seu computador
  1. Clique em "Analisar"
  1. Aguarde o processamento (o botão ficará desabilitado durante o processo)

Dicas para Upload

  • Certifique-se de que o arquivo contém texto legível
  • Arquivos muito grandes podem demorar mais para processar
  • Verifique se o arquivo não está corrompido

🔍 Análise e Resultados

Processamento

Durante o processamento, o sistema:

  1. Extrai o texto do arquivo enviado
  1. Limpa e formata o conteúdo
  1. Envia para análise via IA (DeepSeek)
  1. Processa e estrutura o resultado

Visualização dos Resultados

Após o processamento, você verá:

  • Informações do Processo: Número, status e data
  • Resultado da Análise: Texto formatado e estruturado
  • Botões de Ação: Para baixar PDF ou iniciar novo processo

Estrutura do Resultado

O resultado inclui:

  • Resumo executivo
  • Pontos principais da sentença
  • Análise jurídica detalhada
  • Conclusões e recomendações

📄 Geração de PDF

Como Baixar PDF

  1. Na página de resultados, clique em "Baixar como PDF"
  1. O arquivo será gerado automaticamente
  1. O download iniciará com o nome baseado no número do processo

Características do PDF

  • Formatação profissional
  • Texto estruturado e legível
  • Nome do arquivo baseado no número do processo
  • Pronto para impressão ou compartilhamento

📚 Histórico de Processos

Acessando o Histórico

  1. No menu superior, clique em "Histórico"
  1. Visualize todos os processos anteriores
  1. Use os filtros para encontrar processos específicos

Informações do Histórico

Para cada processo, você verá:

  • Número do Processo: Identificação única
  • Status: Pendente, Processando, Concluído ou Erro
  • Data de Criação: Quando foi enviado
  • Ações: Botões para visualizar resultados

Status dos Processos

  • 🟡 Pendente: Aguardando processamento
  • 🔵 Processando: Em análise pela IA
  • 🟢 Concluído: Processamento finalizado
  • 🔴 Erro: Problema durante o processamento

🔧 Funcionalidades Avançadas

Navegação

  • Início: Retorna à página principal
  • Histórico: Lista todos os processos
  • Novo Processo: Inicia uma nova análise

Mensagens do Sistema

O sistema exibe mensagens para:

  • Confirmação de ações
  • Avisos importantes
  • Erros e problemas

❗ Solução de Problemas

Problemas Comuns

Arquivo não é aceito

  • Verifique se o formato é PDF ou TXT
  • Certifique-se de que o arquivo não está corrompido

Processamento muito lento

  • Arquivos grandes demoram mais
  • Verifique sua conexão com a internet
  • Aguarde alguns minutos antes de tentar novamente

Erro durante o processamento

  • Verifique se o arquivo contém texto legível
  • Tente com um arquivo menor
  • Entre em contato com o suporte se o problema persistir

PDF não é gerado

  • Verifique se o wkhtmltopdf está instalado
  • Tente gerar o PDF novamente
  • Entre em contato com o administrador

Mensagens de Erro

  • "Nenhum arquivo enviado": Selecione um arquivo antes de clicar em Analisar
  • "Arquivo inválido": O arquivo está corrompido ou em formato não suportado
  • "Erro ao processar": Problema durante a análise - tente novamente

💡 Dicas de Uso

Para Melhores Resultados

  1. Use arquivos de qualidade: Textos claros e bem formatados
  1. Verifique o conteúdo: Certifique-se de que é uma transcrição jurídica
  1. Aguarde o processamento: Não interrompa o processo
  1. Salve os resultados: Baixe o PDF para seus arquivos

Boas Práticas

  • Organize seus arquivos antes do upload
  • Use nomes descritivos para identificar processos
  • Mantenha backup dos arquivos originais
  • Revise sempre os resultados gerados

🔒 Segurança e Privacidade

Proteção de Dados

  • Todos os uploads são protegidos
  • Dados são processados de forma segura
  • Informações não são compartilhadas com terceiros

Recomendações

  • Não compartilhe links de resultados
  • Faça logout ao usar computadores compartilhados
  • Mantenha suas credenciais seguras

📞 Suporte

Quando Entrar em Contato

  • Erros persistentes no sistema
  • Problemas com geração de PDF
  • Dúvidas sobre funcionalidades
  • Sugestões de melhorias

Informações para o Suporte

Ao entrar em contato, forneça:

  • Descrição detalhada do problema
  • Tipo e tamanho do arquivo
  • Mensagens de erro exibidas
  • Navegador e sistema operacional utilizados
