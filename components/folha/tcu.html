Contexto do Projeto

O Monitor TCU foi desenvolvido para eliminar o processo manual de consulta ao sistema do Tribunal de Contas da União (TCU), automatizando a verificação do status de aposentadorias. O sistema realiza consultas periódicas e notifica automaticamente os gestores sobre mudanças no status dos servidores.

Etapas de Desenvolvimento

01

Integração com API TCU

Implementação de conexão segura com a API do TCU para consultas automatizadas.

02

Monitoramento Contínuo

Criação de rotina automatizada de verificação e atualização dos status dos servidores.

03

Sistema de Notificações

Configuração de alertas automáticos para os gestores quando há alteração de status.

04

Interface de Gestão

Desenvolvimento de painéis intuitivos para visualização dos servidores monitorados e seu histórico.

Aplicações Desenvolvidas

Resultados Alcançados

O Monitor TCU reduziu em 90% o tempo de verificação manual e eliminou atrasos na identificação de servidores com aposentadoria deferida. O sistema permite que o setor de folha de pagamento atue proativamente, aumentando a eficiência e a precisão dos processos.
