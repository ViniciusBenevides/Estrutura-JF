Contexto do Projeto

Desenvolvido para eliminar o processo manual de verificação individual de cada servidor no sistema do TCU, o TCU Monitor realiza consultas automáticas periódicas e atualiza os status em tempo real. O projeto surgiu da necessidade de agilizar a identificação de servidores com direito à aposentadoria aprovada, permitindo ações rápidas por parte da equipe de folha de pagamento.

Etapas de Desenvolvimento

01

Integração com API do TCU

Desenvolvimento da conexão segura com o sistema do TCU para consulta automatizada dos status de aposentadoria.

02

Sistema de Monitoramento Contínuo

Implementação de rotinas automatizadas para verificação periódica dos servidores cadastrados.

03

Módulo de Notificações

Configuração de alertas automáticos para os gestores quando houver mudança no status de qualquer servidor monitorado.

04

Interface de Gestão

Desenvolvimento de painéis intuitivos para visualização dos status e histórico de alterações.

Principais Funcionalidades

Lista de Pessoas

Painel completo com lista atualizada de todos os servidores monitorados, apresentando de forma clara e organizada o status, CPF, matrícula e outras informações relevantes de cada um.

Cadastro de Servidores

Sistema inteligente de cadastro com validação em tempo real, garantindo que os dados informados estejam corretos e completos, evitando inconsistências e erros futuros.

Edição de Servidores

Fluxo seguro para atualização de dados dos servidores, com histórico de alterações e controle de permissões para garantir a integridade das informações.

Detalhes Pessoais

Visão detalhada de cada servidor com todas as informações relevantes para análise, incluindo dados pessoais, históricos e status de aposentadoria.

Resultados Alcançados

O TCU Monitor reduziu em 90% o tempo gasto com verificações manuais no sistema do TCU e eliminou atrasos no processamento de aposentadorias, permitindo maior agilidade, eficiência e segurança na gestão de processos.
