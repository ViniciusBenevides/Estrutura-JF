LicitaFácil - Extensão de Captura

Extensão de navegador desenvolvida para automatizar a captura de dados de portais de compras públicas e sistemas internos, permitindo a integração direta com o LicitaFácil. A ferramenta reduz etapas manuais, acelera a coleta de informações e garante padronização no fluxo licitatório.

Contexto do Projeto

A Extensão de Captura foi desenvolvida como um módulo do ecossistema LicitaFácil, com o objetivo de extrair automaticamente informações de portais de licitação, sistemas governamentais e páginas SEI. O projeto surgiu da necessidade de eliminar etapas manuais no processo de coleta e consolidação de dados para os setores de compras e licitação, garantindo maior integridade e agilidade.

A solução opera diretamente no navegador, utilizando automação de interface, leitura OCR e análise de conteúdo em tempo real. Os dados capturados são enviados para a API central do LicitaFácil, que realiza o processamento, validação e armazenamento seguro.

Etapas de Desenvolvimento

01

Levantamento e Análise

Mapeamento de portais de licitação e definições de elementos HTML e APIs alvo. Identificação de regras de extração, autenticação e restrições de acesso.

02

Desenvolvimento da Extensão

Implementação do Manifest V3, scripts de conteúdo e background para captura de dados, comunicação assíncrona com a API do LicitaFácil e armazenamento local criptografado.

03

Integração e Backend

Conexão segura via REST API com o servidor central. Implementação de filas de processamento e registro de logs no backend em Python/Flask.

04

Validação e Auditoria

Criação de dashboards de controle e logs detalhados, com validação automática das coletas usando modelos de IA para detecção de inconsistências e duplicidades.

Principais Funcionalidades

Captura Automática de Dados

Leitura de páginas de portais públicos e extração estruturada de informações sobre editais, atas, fornecedores e cotações.

Reconhecimento OCR Integrado

Uso de OCR com Tesseract.js para identificar texto em PDFs e imagens anexadas aos processos licitatórios.

Interface Intuitiva

Botões contextuais e pop-ups no navegador que permitem iniciar, pausar ou revisar coletas sem sair da página em análise.

Sincronização com o LicitaFácil

Envio automático dos dados coletados para o sistema principal, com validação e armazenamento seguro no banco PostgreSQL.

Resultados Alcançados

A Extensão de Captura reduziu em 80% o tempo gasto na coleta manual de informações e aumentou a confiabilidade dos dados processados pelo LicitaFácil. O uso de OCR e integração automática garantiu padronização e eliminação de erros de digitação, além de facilitar auditorias internas.

Com o novo fluxo, as equipes conseguem acompanhar o status das coletas em tempo real, validar documentos instantaneamente e gerar relatórios consolidados sem necessidade de retrabalho.
